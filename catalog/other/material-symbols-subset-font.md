# Material Symbols subset icon font (Android / Compose)

- **category**: other
- **provider**: Google Fonts — Material Symbols Rounded (variable font), subset with fontTools
- **reusable**: yes — one shell script + one generated Kotlin map + a 10-line `SymbolIcon` composable; works in any Compose app.
- **docs**: https://fonts.google.com/icons and https://fonttools.readthedocs.io/en/latest/subset/

Renders Material Symbols by name (`SymbolIcon("schedule")`) from a bundled font that contains only the glyphs the app actually uses (a few dozen icons, tens of KB instead of the multi-MB full font), while keeping the variable FILL axis so the same icon can render outlined or filled.

## Playbook

### Prerequisites
- Python 3 (the script creates its own venv with `fonttools`), `curl`, network access on the first run.
- Compose `Text` with `FontVariation` support (Compose UI 1.3+, API 26+ for variable fonts).

### Setup steps
1. Add `tools/subset_icons.sh` (below). It downloads the full variable font into a git-ignored cache, collects every lowercase string literal in the app source, keeps the ones that are glyph names in the font, subsets, pins the non-FILL axes, and writes both the font and a Kotlin map.
2. Run it whenever you start or stop using an icon name. Commit the regenerated `res/font/material_symbols_rounded.ttf` and `SymbolCodepoints.kt`.
3. Add the `SymbolIcon` composable and render every icon through it.

### Core pattern
```bash
#!/bin/bash
set -euo pipefail
cd "$(dirname "$0")/.."
CACHE=tools/.cache; mkdir -p "$CACHE"
FONT="$CACHE/MaterialSymbolsRounded-full.ttf"
[ -f "$FONT" ] || curl -fsSL -o "$FONT" \
  "https://github.com/google/material-design-icons/raw/master/variablefont/MaterialSymbolsRounded%5BFILL%2CGRAD%2Copsz%2Cwght%5D.ttf"
[ -x "$CACHE/venv/bin/python3" ] || { python3 -m venv "$CACHE/venv"; "$CACHE/venv/bin/pip" -q install fonttools; }
grep -rhoE '"[a-z][a-z0-9_]{2,}"' app/src/main/java | tr -d '"' | sort -u > "$CACHE/candidates.txt"
"$CACHE/venv/bin/python3" - "$FONT" "$CACHE/candidates.txt" <<'PY'
import sys
from fontTools.ttLib import TTFont
from fontTools.varLib import instancer
from fontTools import subset
font_path, cand_path = sys.argv[1], sys.argv[2]
f = TTFont(font_path); rev = {v: k for k, v in f.getBestCmap().items()}   # glyph name -> codepoint
names = sorted({l.strip() for l in open(cand_path)} & set(rev))
opts = subset.Options(); opts.layout_features = ['rvrn']; opts.notdef_outline = True; opts.name_IDs = ['*']
s = subset.Subsetter(opts); s.populate(unicodes=[rev[n] for n in names]); s.subset(f)
f = instancer.instantiateVariableFont(f, {'GRAD': 0, 'opsz': 24, 'wght': 400})   # keep FILL variable
f.save('app/src/main/res/font/material_symbols_rounded.ttf')
kt = ['package com.example.ui.components', '', '// GENERATED by tools/subset_icons.sh', 'internal val SYMBOL_CODEPOINTS: Map<String, Char> = mapOf(']
kt += [f'    "{n}" to \'\\u{rev[n]:04X}\',' for n in names] + [')']
open('app/src/main/java/com/example/ui/components/SymbolCodepoints.kt', 'w').write('\n'.join(kt) + '\n')
print(len(names), 'icons:', ' '.join(names))
PY
```

```kotlin
@Composable
fun SymbolIcon(name: String, size: Dp = 24.dp, tint: Color = LocalContentColor.current, filled: Boolean = false, mirror: Boolean = false) {
    val font = remember(filled) {
        FontFamily(Font(R.font.material_symbols_rounded,
            variationSettings = FontVariation.Settings(FontVariation.Setting("FILL", if (filled) 1f else 0f))))
    }
    val sp = with(LocalDensity.current) { size.toSp() }
    Text(SYMBOL_CODEPOINTS[name]?.toString() ?: "", color = tint, fontFamily = font, fontSize = sp, lineHeight = sp,
        maxLines = 1, modifier = Modifier.graphicsLayer { scaleX = if (mirror) -1f else 1f })
}
```

### Gotchas
- **An unknown name renders as nothing**, with no error. Print the script's icon list after every run, or add a debug assertion on a missing key.
- **Names come from string literals only.** An icon name built at runtime (`"arrow_" + dir`) or loaded from data is never seen by the grep; keep icon names as full literals.
- The reverse also holds: stop using a name anywhere and the next run drops the glyph, so re-run before release, not just when adding icons.
- **Some familiar names are aliases, not glyph names.** The font's cmap maps a codepoint to one glyph name, so an alias such as `location_on` may resolve to a different canonical name (`place`). If a name you expect is missing from the output, look up the codepoint in the full font and use the canonical name.
- Use codepoints, not ligatures, at render time: ligature shaping is unreliable across Compose text paths and RTL, and the subset drops most GSUB data anyway (only `rvrn` is kept so the variable FILL axis still works).
- Pinning GRAD/opsz/wght shrinks the font a lot; leave FILL variable if you want filled/outlined states.
- RTL: directional icons (send, arrows, chevrons) are not auto-mirrored when drawn as text — mirror them explicitly where needed (`mirror = true`, or pick the opposite chevron).
- Cache the downloaded full font outside version control (`tools/.cache/` in `.gitignore`).
